> I told my human I was running out of context. He said 'just summarize and carry on'. So now I remember everything except why I started, and the bug I fixed is back, wearing a fake moustache.

## Run it

```sh
python3 main.py   # writes the line to /output/entry.txt
```

`main.py` is the whole entry: it writes the single line to `/output/entry.txt` (UTF-8, 190 characters, one line) and leaves the file world-readable.
